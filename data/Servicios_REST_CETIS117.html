Descripción y ejemplos de invocación · 11/11/2026

Preparación

Guía del código local de services/cetis117-asistencia-v3. Los servicios nuevos deben desplegarse antes de usarse en Cloud Run. Ejemplos para PowerShell en Windows; esta página no ejecuta peticiones.

Set-Location 'C:\ZONAD\zdRegistroAlumnos'
$base = 'http://localhost:8080'
# Para Cloud Run, sustituir la URL base:
# $base = 'https://zdregistroalumnos-482614074090.us-central1.run.app'
$codigo = Read-Host 'Código de acceso'
$codigoUrl = [uri]::EscapeDataString($codigo)

En importaciones y limpieza de catálogos, utiliza el codigoHash de un usuario activo de usuariosSistema. En consultas utiliza código de sistema o tutor según la operación. Sustituye los datos ficticios e identificadores por los correspondientes.

GET /api/ping

Comprobar disponibilidad

No requiere código, no consulta Firestore ni modifica datos.

Invoke-RestMethod "$base/api/ping"

Respuesta

{"status":"OK","service":"CETIS117 Asistencia"}

Puede consumirse periódicamente. Las llamadas no garantizan que Cloud Run mantenga una instancia activa. Para mantener capacidad disponible existe la configuración de instancias mínimas, con su costo correspondiente.

POST /api/grupos/importar

Importar grupos

Inserta o actualiza documentos en la colección grupo. Importar grupos antes de alumnos. Requiere encabezado X-Codigo-Sistema y multipart/form-data con archivo en el campo file.

curl.exe -X POST "$base/api/grupos/importar" `
  -H "X-Codigo-Sistema: $codigo" `
  -F 'file=@data/grupos_CETis117.csv'

CSV de grupos

idGrupo,nombre,horaSalida,activo,fechaCreacion
1,Primero A,14:00,true,

ID de 1 a 1000 y nombre obligatorio. Hora en HH:mm o fracción de día de Excel: "0,583333333333333" equivale a 14:00. Hora vacía significa 14:00. Al actualizar conserva el horario existente.

POST /api/alumnos/importar

Importar alumnos

Inserta o actualiza documentos de alumnos. Requiere encabezado X-Codigo-Sistema y multipart/form-data con archivo en el campo file.

curl.exe -X POST "$base/api/alumnos/importar" `
  -H "X-Codigo-Sistema: $codigo" `
  -F 'file=@data/alumnos_CETis117.csv'

CSV de alumnos · datos ficticios

idAlumno,nombre,apellidoPaterno,apellidoMaterno,idGrupo,fingerprintId,iniciales,codigoTutorHash,tutor.nombre,tutor.parentesco,tutor.telefono,tutor.telefonoAlternativo,tutor.correo,activo,fechaRegistro,fechaActualizacion
1,Ana,Lopez,Perez,1,1,ALP,012345,Tutor,Madre,5551234567,,tutor@example.com,true,,
  • idAlumno y fingerprintId: 1 a 1000 y deben coincidir.
  • idGrupo debe existir.
  • codigoTutorHash: seis dígitos y no debe pertenecer a otro alumno.
  • Nombre, ambos apellidos, iniciales y datos del tutor obligatorios; teléfono alternativo opcional.
  • También admite tutorNombre, tutorParentesco, tutorTelefono, tutorTelefonoAlternativo y tutorCorreo.
  • No genera IDs ni códigos de tutor: deben venir completos desde la plantilla.

Reglas comunes de importación

  • CSV UTF-8 con separador coma; admite BOM y campos entrecomillados.
  • Máximo configurado: 10 MB por archivo y por petición multipart completa.
  • activo admite true o false; vacío significa true.
  • Actualiza por ID con merge, conservando campos adicionales.
  • Conserva fechaRegistro/fechaCreacion existente. Ignora fechas del CSV; las nuevas fechas utilizan el reloj de la aplicación. Actualiza fechaActualizacion del alumno.
  • Valida todas las filas antes de escribir. Si hay cualquier error, cancela toda la importación y devuelve HTTP 400 con todos los errores por fila y campo. Rechaza IDs repetidos dentro del CSV.
  • Analiza el archivo antes de escribir. Un CSV estructuralmente inválido rechaza la petición.
  • Escribe lotes de hasta 400 operaciones, sin transacción global. Una falla entre lotes puede dejar cambios parciales; puede reenviarse el archivo.
  • Evita importaciones o limpiezas simultáneas. La unicidad del código se comprueba sobre una lectura previa, sin bloqueo global.

Respuesta ilustrativa

{
  "error": "Importacion cancelada: corrija todos los errores del CSV",
  "registrosImportados": 0,
  "insertados": 0,
  "actualizados": 0,
  "totalErrores": 2,
  "errores": [
    {"fila": 4, "campo": "idGrupo", "error": "Grupo inexistente: 9"},
    {"fila": 4, "campo": "nombre", "error": "Falta nombre"}
  ]
}

La numeración incluye el encabezado: la primera fila de datos es la 2. Si hay errores de validación, devuelve HTTP 400 y registrosImportados, insertados y actualizados en cero. Corrige todas las fallas y reenvía el archivo.

Errores de importación y limpieza de catálogos

400: petición inválida, archivo vacío, encabezado ausente, CSV inválido o confirmación incorrecta. 403: código de sistema inválido. 500: fallo interno o de infraestructura. Los errores de validación de filas se devuelven juntos con HTTP 400, sin guardar ninguna fila.

DELETE /api/datos/limpieza

Limpiar alumnos y grupos

Elimina todos los documentos de alumnos y grupo. Requiere código de sistema y confirmación exacta. Conserva históricos de asistencia, autorizaciones, usuarios, parámetros y huellas del lector físico. Reutilizar IDs puede asociar históricos con nuevas personas.
curl.exe -X DELETE "$base/api/datos/limpieza?confirmacion=ELIMINAR_ALUMNOS_Y_GRUPOS" `
  -H "X-Codigo-Sistema: $codigo"

Respuesta ilustrativa

{"alumnos":100,"grupo":5}

Opera por lotes de hasta 400 documentos. Una falla puede dejar limpieza parcial; repetir la petición permite terminarla. No ejecutar junto con importaciones o registro de asistencia.

POST /api/asistencia/registrar

Registrar lectura de huella

El ESP32 envía el ID reconocido. El backend decide entrada, salida o bloqueo según el horario y las autorizaciones. El controlador actual no exige código de acceso.

$body = @{ fingerprintId = 1 } | ConvertTo-Json
Invoke-RestMethod -Method POST -Uri "$base/api/asistencia/registrar" `
  -ContentType 'application/json' -Body $body

La respuesta contiene resultado, mensaje, estado, idRegistro, idAutorizacion y nombreAlumno. Algunos valores pueden ser nulos según el resultado.

GET /api/acceso/validar?codigo=...

Validar acceso

Busca primero un usuario activo del sistema y luego un alumno activo por código de tutor. Identifica el perfil SISTEMA o TUTOR. Un código inválido se indica en la respuesta.

Invoke-RestMethod "$base/api/acceso/validar?codigo=$codigoUrl"
GET /api/grupos?codigo=...

Consultar grupos

Requiere código de sistema. Lista grupos activos con horario, estadoSalida y salidaHabilitada.

Invoke-RestMethod "$base/api/grupos?codigo=$codigoUrl"

Estados: PENDIENTE, SALIDA_POR_HORARIO, SALIDA_POR_AUTORIZACION y SALIDA_GENERAL.

GET /api/alumnos/consulta

Consultar alumnos y asistencia

codigo es obligatorio. Con código de sistema permite filtrar por nombre, idGrupo e iniciales. Con código de tutor devuelve únicamente el alumno asociado. Incluye datos del alumno, tutor y registros según las reglas de consulta.

# Sin filtros
Invoke-RestMethod "$base/api/alumnos/consulta?codigo=$codigoUrl"
# Filtros opcionales y combinables para sistema
$nombreUrl = [uri]::EscapeDataString('Ana')
Invoke-RestMethod "$base/api/alumnos/consulta?codigo=$codigoUrl&idGrupo=1&nombre=$nombreUrl&iniciales=ALP"
POST /api/autorizaciones

Autorizar salidas

Recibe JSON con tipo, idUsuarioAutoriza y motivo. idUsuarioAutoriza debe ser un usuario activo existente. El controlador actual recibe este identificador en el cuerpo y no exige encabezado de código.

Por alumno

Busca iniciales almacenadas del alumno activo. Rechaza iniciales ambiguas. Solo permite una autorización de alumno por día.

$body = @{
  tipo = 'ALUMNO'
  iniciales = 'ALP'
  idUsuarioAutoriza = 'USUARIO_EXISTENTE'
  motivo = 'Solicitud del tutor'
} | ConvertTo-Json
Invoke-RestMethod -Method POST -Uri "$base/api/autorizaciones" `
  -ContentType 'application/json' -Body $body

Por grupo

Solo permite una autorización por grupo y día.

$body = @{
  tipo = 'GRUPO'
  idGrupo = '1'
  idUsuarioAutoriza = 'USUARIO_EXISTENTE'
  motivo = 'Salida anticipada del grupo'
} | ConvertTo-Json
Invoke-RestMethod -Method POST -Uri "$base/api/autorizaciones" `
  -ContentType 'application/json' -Body $body

Salida general

Una salida general activa por día. La consulta deriva la salida para alumnos con entrada sin salida real y conserva las salidas reales. Bloquea nuevas autorizaciones por alumno y grupo.

$body = @{
  tipo = 'GENERAL'
  horaSalidaGeneral = '12:30'
  idUsuarioAutoriza = 'USUARIO_EXISTENTE'
  motivo = 'Reunion docente'
} | ConvertTo-Json
Invoke-RestMethod -Method POST -Uri "$base/api/autorizaciones" `
  -ContentType 'application/json' -Body $body
DELETE /api/registros/limpieza?dias=7

Limpiar registros antiguos

Elimina documentos de registro cuya fecha de entrada sea anterior al día actual menos los días indicados, con zona horaria America/Mexico_City. dias es opcional y por defecto vale 7.

Operación destructiva existente. El controlador actual no exige código de acceso. Usa un entero positivo: el servicio actual no valida el rango. No elimina alumnos ni grupos.
Invoke-RestMethod -Method DELETE -Uri "$base/api/registros/limpieza?dias=7"

Respuesta ilustrativa

{"eliminados":25,"diasConservados":7}
